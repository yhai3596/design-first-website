# P4 走查循环：五问题法

## 流程（每轮 ≤2 项修改，循环至达标）

1. **起服务开浏览器**：静态站可 `preview_start` 直开文件服务；平台站起 dev server。
2. **双端截图**：桌面 1280 宽 + 移动 preset，各截首屏与整页关键区块。
3. **对照 DESIGN.md 列 5 个具体问题**——必须具体到元素，禁止"整体感觉不够高级"这种废话。检查维度：
   - **首屏表达**：3 秒能看出"这是谁/干什么/让我做什么"吗？主标题是 DESIGN.md 里那句吗？
   - **颜色纪律**:有没有 DESIGN.md 之外的颜色混进来（包括默认蓝链接、未改的边框灰）？
   - **字级层次**：标题够不够大？正文/辅助文字拉开差距没有？行宽是否过长（>75 字符）？
   - **模板感**：卡片是不是千篇一律三列等宽？有没有 AI 味黑名单里的项（对照 DESIGN.md 第 12 节逐条扫）？
   - **素材占位感**：图片是不是明显占位图/风格不搭？
   - **移动端**：横向溢出？文字挤压？触点太小（<44px）？首屏还成立吗？
4. **逐项修**：每轮挑最伤的 1-2 项修，改完重截图对比。**禁止**"不满意→推倒重写整页"——走查只做定向修改。
5. **收敛判定**：连续一轮列不出违背 DESIGN.md 的具体问题 → 呈给用户看双端截图 → 用户点头 = 完成。用户提新需求 → 回 DESIGN.md 改文档再改码。

## 素材规格单（问题出在图片时）

不要硬改 CSS 去糊弄一张不合适的图。输出规格单让用户提供或生成：

```
位置：首屏右侧主视觉
尺寸：约 800×1000（竖版）
风格：与 DESIGN.md 颜色节一致（如：米白背景、低饱和）
主体：<具体主体>
氛围：<两三个形容词>
禁止：水印、无关文字、与站点撞色
```

生成通道：`imagegen-frontend-web`（网页素材）/ `brandkit`（logo·品牌图形）。生成后放入素材目录并更新 DESIGN.md 第 9 节的来源标注。

## 常见误判

- 「看不到问题」≠ 通过——必须基于正向证据（截图里逐维度核对过）才能收敛（本机规则 5.8）。
- 浏览器缓存导致"改了没生效"：强刷或加查询串，别急着怀疑代码。
- dev server 僵尸进程占端口 → 换端口起，禁止按进程名批杀（本机规则 5.7）。
